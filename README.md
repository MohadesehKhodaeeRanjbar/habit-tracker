## 🎯 مسئله
بسیاری از افراد می‌خواهند عادت‌های خوب (ورزش، مطالعه، آب‌خوردن) بسازند، اما بدون پیگیری منظم آن‌ها را فراموش می‌کنند و نمی‌دانند چقدر پیشرفت کرده‌اند. دفترچه همیشه همراه نیست و اپلیکیشن‌های شلوغ معمولاً رها می‌شوند.

## ✨ قابلیت‌های اصلی
- تعریف عادت با عنوان و تکرار (روزانه یا هفتگی)
- ثبت انجام‌شدن عادت در هر روز
- یادآور در ساعت دلخواه
- نمایش تعداد روزهای پیاپی
- آمار هفتگی و ماهانه
- ویرایش و حذف عادت‌ها

## 🧩 مخاطب‌ها
- دانشجویان و کارمندانی که می‌خواهند روتین روزانه بسازند
- افرادی که به دنبال ابزار ساده برای خودمدیریتی هستند

## 🛠 فناوری‌های پیشنهادی
- وب: React + Node.js (Express)
- پایگاه داده: PostgreSQL (یا SQLite برای شروع)
- یادآور: اعلان مرورگر (Web Notifications)
- نمودار: Chart.js
